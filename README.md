# 🏰 Tower of English

تطبيق ويب تفاعلي (Gamified) لتعليم الإنجليزية لطلاب الجامعة: سباق بين فريقين
لصعود برج من 10 طوابق. كل إجابة صحيحة تصعد بالفريق طابقاً، وأول فريق يصل
للطابق 10 يفوز.

**Tech stack:** Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 ·
Framer Motion · Lucide Icons · Supabase (Auth + Realtime + Postgres RPC) ·
Vitest + Testing Library · جاهز للنشر على Vercel.

## ▶️ التشغيل محلياً

```bash
npm install
cp .env.local.example .env.local   # أضف بيانات Supabase
npm run dev                        # http://localhost:3000
```

بدون إعداد Supabase تعمل الصفحات العامة فقط: الصفحة الرئيسية `/` وـ
`/demo` (playground كامل بلا حساب). أي زيارة لـ `/lobby` أو `/room/*` تُحوّل
تلقائياً إلى `/login` مع رسالة توضح أن الإعداد ناقص.

### إعداد Supabase

1. أنشئ مشروعاً على supabase.com وشغّل الملفات بالترتيب في **SQL Editor**:
   - `supabase/schema.sql` (جداول + RPCs الخطوة الأولى)
   - `supabase/migrations/0002_step2_gameplay.sql` (مصادقة اللعب + RPCs الجديدة)
   - `supabase/migrations/0003_roles_teacher_stats.sql` (الأدوار + لوحة المدرس + الإحصائيات + 20 سؤالاً إضافياً)
2. من **Project Settings → API** انسخ URL والـ anon key إلى `.env.local`.
3. (اختياري) من **Authentication → Providers** عطّل "Confirm email" لتجربة
   تسجيل فورية أثناء التطوير.

## 🔐 Step 2 — المصادقة وتدفق اللعب الكامل

### المسارات

| المسار | الوظيفة |
| --- | --- |
| `/` | صفحة هبوط مع رابط الدخول وـ demo |
| `/login` | تسجيل دخول / إنشاء حساب (Supabase Auth) مع تحقق من المدخلات |
| `/lobby` | إنشاء غرفة، الانضمام بكود من 6 أحرف، وقائمة الغرف المفتوحة |
| `/room/[code]` | غرفة اللعب: انتظار، Presence، البرج، السؤال والمؤقّت، الاحتفال |
| `/demo` | playground محلي بلا اتصال ولا حساب |
| `/auth/callback` | تبادل رمز تأكيد البريد لجلسة كاملة |

### الأمان: الإجابة الصحيحة لا تغادر قاعدة البيانات قبل الإجابة

- سياسة القراءة المباشرة على جدول `questions` أُلغيت في ترحيل Step 2، فلم يعد
  بإمكان أي عميل رؤية `correct_key`.
- العميل يجلب السؤال عبر RPC `get_question` الذي يعيد الحقول الآمنة فقط
  (النص والخيارات دون المفتاح).
- بعد الإجابة، يعيد RPC `answer_question` نتيجة مركّبة: حالة الغرفة المحدّثة +
  صحة الإجابة + المفتاح الصحيح + التفسير، فتُعرض تغذية راجعة فورية.

### مزامنة لحظية بثلاث طبقات Realtime

1. **postgres_changes** على صف الغرفة (`useRoomChannel`) لحركة الفريقين.
2. **Presence** على قناة مستقلة (`useRoomPresence`) لمعرفة اللاعبين المتصلين.
3. بوابة `version` تتجاهل أي حدث قديم يصل بترتيب خاطئ.

### مؤقّت الجولة (20 ثانية)

- `useCountdown` يعيد تشغيل نفسه تلقائياً مع كل سؤال جديد (مفتاح إعادة التشغيل
  هو معرّف السؤال) ويطلق حدث الانتهاء مرة واحدة فقط.
- عند انتهاء الوقت يستدعي العميل RPC `expire_turn` الذي يدوّر الدور دون تحريك
  أي فريق ويسحب السؤال التالي — والحراس الذرية تمنع انتهاء الدور مرتين من
  جهازين مختلفين.

### Race conditions في الانضمام أيضاً

`join_room` يستخدم `SELECT ... FOR UPDATE` على صف الغرفة، فلا يمكن للاعبين
اثنين حجز نفس الخانة في نفس اللحظة، مع إعادة دخول عديمة الأثر (idempotent)
للاعب الموجود أصلاً.

### دوال RPC الجديدة في Step 2

`join_room(code)` · `leave_room(id)` · `get_question(id)` ·
`answer_question(...)` · `expire_turn(id, team)` ·
`list_waiting_rooms()` — وكلها `SECURITY DEFINER` خلف RLS.

## 👩‍🏫 Step 3 — الأدوار، لوحة المدرس، الإحصائيات، والصوت

### الأدوار (student / teacher)

- عمود `role` على `profiles` مع منع الطالب من ترقية نفسه مباشرة عبر صلاحيات
  الأعمدة (`revoke update (role)`) — التغيير فقط عبر RPC `update_my_role`.
- مبدّل أدوار في `/dashboard` (نموذج أولي للقاعة الدراسية؛ في الإنتاج يجب ربط
  ترقية المدرس بموافقة مسؤول).

### لوحة المدرس (`/dashboard` للمدرس)

- جدول بنك الأسئلة مع الطابق والفئة والمفتاح الصحيح وزر أرشفة (حذف ناعم يبقي
  سجل الإجابات سليماً).
- نموذج إنشاء سؤال بتحقق نقي في `questionForm.ts` (طابق 1–10، 4 خيارات فريدة،
  نص لا يقل عن 10 أحرف) ثم RPC `create_question`.
- كل دوال المحتوى (`create_question` / `update_question` /
  `archive_question` / `teacher_list_questions`) ترفض غير المدرسين برمز
  `TEACHER_ONLY` وتعيد المفتاح الصحيح للمدرس فقط.

### الإحصائيات والمتصدرين

- RPCs: `get_my_stats` (مباريات/انتصارات/إجابات/دقة)، `get_leaderboard`
  (ترتيب على مستوى القاعدة)، و`get_my_matches` (آخر 20 مباراة).
- منطق الترتيب والعرض النقي في `stats.ts` مع اختبارات: انتصارات ثم إجابات
  صحيحة ثم الدقة ثم الاسم، وميداليات ذهبية/فضية/برونزية لأول ثلاثة.

### المؤثرات الصوتية (بلا ملفات خارجية)

- `useSoundFx` يولّد النغمات عبر Web Audio API: صعود صحيح، خطأ، تكتكة آخر 5
  ثوانٍ، ولحن فوز رباعي. زر كتم يحفظ التفضيل في `localStorage`، ويفشل بصمت
  إن منع المتصفح الصوت.

### بنك أسئلة موسّع

ترحيل Step 3 يضيف 20 سؤالاً جديداً (سؤالان إضافيان لكل طابق) بمختلف الفئات،
وليصبح إجمالي البنك 30 سؤالاً.


تغطي الاختبارات:

- **قواعد النقاط** — صعود طابق واحد، سقف الطابق 10، تدوير الأدوار، الشارات.
- **تزامن الغرفة** — تجاهل الأحداث القديمة، تقارب الأحداث بترتيب عشوائي،
  محاكاة إجابتين في نفس اللحظة، رفض النقر المزدوج.
- **Step 2** — reducer جولة السؤال بكل حالاته، المؤقّت بمؤقّتات وهمية
  (fake timers)، Presence مع إزالة التكرار، نموذج المصادقة، اللوبي، بطاقة
  السؤاق وكشف الإجابة الصحيحة/الخاطئة، التحقق من المدخلات ورموز الغرف.
- **Step 3** — حسابات الدقة ومعدل الفوز وترتيب المتصدرين والميداليات، تحقق
  نموذج المدرس، محرك الصوت Web Audio بمحاكاة AudioContext، لوحة المدرس
  (إنشاء/أرشفة)، ومكوّنات الإحصائيات والمتصدرين.

## 🛡️ طبقات منع Race Conditions (ملخص)

1. لا كتابة مباشرة من العملاء — RLS يحجبها وكل التعديلات عبر RPC.
2. `SELECT ... FOR UPDATE` يسلسل الإجابات/الانضمامات المتزامنة.
3. قيد فريد `(room_id, question_id, team)` يرفض الإجابة المكررة.
4. عدّاد `version` + `mergeRoomState` يحمي الواجهة من الأحداث القديمة.

## ☁️ النشر على Vercel

1. ارفع المستودع إلى GitHub واستورده في Vercel.
2. أضف متغيرات البيئة `NEXT_PUBLIC_SUPABASE_URL` و
   `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
3. فعّل Middleware تلقائياً لحماية المسارات — لا إعدادات إضافية.

## 🗺️ الخطوات التالية المقترحة (Step 4)

- موافقة مسؤول على ترقية المدرس بدل التبديل الحر، وصفحات إدارة المستخدمين.
- فئات أسئلة الاستماع بملفات صوتية، وأسئلة كتابة بتصحيح جزئي.
- أوضاع مباريات أطول (أفضل من 3 جولات) وتحديات فردية بلا خصم.
- لوحة تحكم أستاذ حية لمتابعة القاعة أثناء اللعب وتصدير النتائج (CSV/PDF).
- PWA وتثبيت على الجوال مع إشعارات لحظية.
